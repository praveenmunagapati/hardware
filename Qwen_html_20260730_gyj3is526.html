ISA REFERENCE — MINI-EVO/8

MEMORY MAP — 0x00–0x7F code · 0x80–0xDF variables · 0xE0–0xFF expression stack (SP starts at 0xFF, grows down).
REGISTERS — R0 accumulator, R1 scratch (reserved by the compiler) · R2, R3 free · all values are 8-bit, arithmetic wraps mod 256.
FLAGS — Z set when a result is 0 · N mirrors bit 7, so jumps JN/JGE/JG/JLE give signed comparisons after CMP.
